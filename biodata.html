Biografi Singkat

Saya mahasiswa Sistem Informasi angkatan 2025 di Fakultas Teknologi Informasi UNAI. Awalnya saya pilih jurusan ini karena penasaran bagaimana sebuah aplikasi dibuat. Sampai sekarang saya masih di bagian tampilan website, jadi HTML dan CSS dulu yang saya kejar.

Di luar kelas saya ikut kegiatan pemuda di gereja. Dari situ saya sering jalan bareng teman-teman: ke Pantai New Melur dan Viovio di Batam, main selancar di Canggu, sampai mendaki Gunung Buthak. Kalau lagi di rumah biasanya main catur atau Mobile Legends. Tahun lalu ikut Korinda Cup dan kebetulan dapat juara 3.

Di mata kuliah Web Programming I saya belajar membuat website dari nol. Minggu 2 masih soal struktur HTML, minggu 3 masuk ke CSS dan box model. Halaman biodata ini yang paling sering saya bolak-balik karena tabelnya paling susah dirapikan.

Hobi & Minat

Yang paling sering saya lakukan

Kalau tidak ada tugas, tiga ini yang biasanya saya kerjakan:

  1. Catur. Biasanya sore, sambil nunggu makan malam.
  2. Mobile Legends. Main sama teman gereja, kadang sampai lupa waktu.
  3. Tidur. Kalau ada kelas pagi, ini hobi yang paling realistis.

Kalau bosan di rumah

Sisanya ini, tergantung mood:

  • Dengar musik. Playlist-nya ikut suasana, dari lagu gereja sampai yang ramai.
  • Nonton film, biasanya bareng keluarga di akhir pekan.
  • Nongkrong dan ngobrol sama teman kampus.
  • Berenang, kalau kebetulan sedang ke pantai.
  • Mendaki. Baru sekali naik Buthak, tapi sudah mau lagi.
